# Maintainer Report

Public preview. Advisory output, not a certification.

## What the report contains

Generated by `generateMaintainerReport` in `src/lib/reports/maintainer-report.ts`:

- Selected repository name
- Generation timestamp and mode (`demo` or `live`)
- Advisory readiness checks (status, confidence, evidence)
- Pending AI drafts grouped by source
- Recent audit log entries (action + timestamp only)
- Recommended next actions (from missing/partial checks)
- Known limitations

## What the report never contains

- Secrets, tokens, API keys, or session data
- Real environment variable values
- Raw request logs
- Claims of production readiness, audit certification, or vendor endorsement

## Generation rules

- Demo mode reports are labelled "demo data" in the header.
- Control characters are stripped from dynamic fields before they are
  rendered into Markdown.
- The disclaimer "Advisory report. MaintainerOS heuristics are not a
  substitute for a formal audit, security review, or production sign-off."
  always appears at the top.

## Distribution

The report is intended for local download or copy/paste only. MaintainerOS
never posts the report to GitHub or anywhere else on its own.
